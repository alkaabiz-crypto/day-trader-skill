# Rules for Claude in this repository

- **One repository only: `alkaabiz-crypto/day-trader-skill`.** Never clone, fetch from, push to,
  open pull requests against, or copy code from any other repository. That includes the original
  upstream `Jakeschincariol/day-trader-skill`: its URL appears in the README and the tools'
  User-Agent strings only as text. Never add another repository to a session for this work.
- Work happens on branches of this repo and is merged into its `main` by pull request.
- Nothing places a real order. Paper trading by default; going live is the owner's decision.
